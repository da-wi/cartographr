# Package index

## Data retrieval and map preprocessing

Functions for obtaining and preparing OpenStreetMap data for urban
environments.

- [`get_osmdata()`](https://da-wi.github.io/cartographr/reference/get_osmdata.md)
  : Retrieve OpenStreetMap Data
- [`preprocess_map()`](https://da-wi.github.io/cartographr/reference/preprocess_map.md)
  : Preprocess OSM Data
- [`crop()`](https://da-wi.github.io/cartographr/reference/crop.md) :
  Crop a preprocessed map

## Plotting and customization

Functions to plot maps with custom themes and save the output.

- [`plot_map()`](https://da-wi.github.io/cartographr/reference/plot_map.md)
  : Plot a map with custom palette
- [`save_map()`](https://da-wi.github.io/cartographr/reference/save_map.md)
  : Save a map to a file
- [`get_palette()`](https://da-wi.github.io/cartographr/reference/get_palette.md)
  : Create a palette for maps

## Configuration and settings

Functions to configure the cartography package settings and output.

- [`print_config()`](https://da-wi.github.io/cartographr/reference/print_config.md)
  : Print configuration details
- [`set_attribution()`](https://da-wi.github.io/cartographr/reference/set_attribution.md)
  : Set or get attribution setting
- [`set_output_size()`](https://da-wi.github.io/cartographr/reference/set_output_size.md)
  : Set output size for maps

## Theming and aesthetics

Functions to apply custom themes and fonts to enhance the visual appeal
of maps.

- [`theme_infomap()`](https://da-wi.github.io/cartographr/reference/theme_infomap.md)
  [`theme_infomap_anton()`](https://da-wi.github.io/cartographr/reference/theme_infomap.md)
  [`theme_infomap_poppins()`](https://da-wi.github.io/cartographr/reference/theme_infomap.md)
  [`theme_infomap_cinzel()`](https://da-wi.github.io/cartographr/reference/theme_infomap.md)
  [`theme_infomap_barlow()`](https://da-wi.github.io/cartographr/reference/theme_infomap.md)
  : Apply infomap theme with specified font
- [`theme_poster()`](https://da-wi.github.io/cartographr/reference/theme_poster.md)
  [`theme_poster_poppins()`](https://da-wi.github.io/cartographr/reference/theme_poster.md)
  [`theme_poster_anton()`](https://da-wi.github.io/cartographr/reference/theme_poster.md)
  [`theme_poster_cinzel()`](https://da-wi.github.io/cartographr/reference/theme_poster.md)
  [`theme_poster_barlow()`](https://da-wi.github.io/cartographr/reference/theme_poster.md)
  : Create a poster theme

## Datasets

  Manhattan crime dataset
- [`osm`](https://da-wi.github.io/cartographr/reference/osm.md) : OSM
  SoHo New York simple features

  : SoHo Boundary Simple Features Vector
