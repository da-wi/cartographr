# OSM SoHo New York simple features

This dataset contains the Simple Features (sf) representation for Soho,
New York. It includes various geographical and spatial attributes
relevant to the area.

## Usage

``` r
osm
```

## Format

An named list of objects of class `sf` with rows and columns
corresponding to the features and their attributes.

## Source

OpenStreetMap

## Examples

``` r
data("osm")
```
